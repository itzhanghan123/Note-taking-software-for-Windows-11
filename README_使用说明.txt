桌边备忘录 14 - 日历高亮与工具栏统一版

本次修改：
1. 日历中当前选中的日期使用蓝底白字高亮。
2. 最近14天之外的日期显示为灰色且不可选；日期范围为今天及之前13天。

5. 保留图片插入、截图粘贴、富文本、自动保存、最近14天、四边吸附、托盘。

打包：
1. 解压 ZIP。
2. 双击 BUILD_EXE.cmd。
3. 运行 dist\DeskMemo14_CalendarToolbar_Polish.exe。

数据保存在 %APPDATA%\DeskMemo14。源码已通过 Python 语法检查，仍需在 Windows 11 实测日历选中样式。
